# SPA-приложение "Custom Clothes" — Лабораторная работа №4

Это одностраничное приложение (SPA) для демонстрации каталога кастомной одежды, разработанное в рамках лабораторной работы №4. Проект построен на React с использованием **Redux Toolkit** для управления состоянием и **i18next** для интернационализации.

## Основные технологии

*   **React** (с использованием хуков)
*   **Redux Toolkit** (для централизованного управления состоянием)
*   **React Router** (для навигации)
*   **React Bootstrap** (для стилизации и компонентов)
*   **i18next** (для интернационализации)

---

## Выполнение требований методички

### Требования к Redux

#### 1. Создано хранилище Redux с использованием `@reduxjs/toolkit`
- **Реализация:** Хранилище (`store`) создано с помощью функции `configureStore` в файле `src/app/store.js`. Оно подключено к приложению через компонент `<Provider>` в `src/index.js`.

#### 2. Реализовано два различных слайса
- **Реализация:** В проекте создано два слайса для управления разными частями состояния:
  - **`productsSlice.js`** (`src/features/products/`): Управляет массивом товаров (CRUD-операции).
  - **`uiSlice.js`** (`src/features/ui/`): Управляет состоянием пользовательского интерфейса (поисковый запрос, порядок сортировки, состояние модального окна).

#### 3. Созданы редьюсеры для CRUD
- **Реализация:**
  - **Create (Создание):** Редьюсер `addProduct` в `productsSlice` добавляет новый товар в массив.
  - **Read (Чтение):** Селектор `selectAllProducts` в `productsSlice` предоставляет доступ к списку товаров.
  - **Update (Обновление):** Редьюсер `updateProduct` в `productsSlice` обновляет данные существующего товара.
  - **Delete (Удаление):** Редьюсер `deleteProduct` в `productsSlice` удаляет товар из массива по ID.

#### 4. Обработка ошибок и валидация данных
- **Реализация:**
  - **Валидация на стороне клиента:** HTML-атрибут `required` в полях формы (`ProductForm.js`) не позволяет отправить пустую форму.
  - **Валидация в Redux:** Редьюсер `addProduct` содержит проверку на наличие обязательных полей (`name`, `price`), предотвращая добавление некорректных данных в `store`.

### Требования к компонентам React

*   **Компоненты для отображения, создания и редактирования:**
    - **`CatalogPage.js`** отображает список товаров, используя `ProductCard.js`.
    - **`ProductForm.js`** представляет собой форму для создания и редактирования, которая отображается внутри модального окна.

*   **Компоненты для фильтрации и сортировки:**
    - На странице `CatalogPage.js` реализованы:
      - Поле `Form.Control` для **фильтрации** (поиска) по названию.
      - Компонент `DropdownButton` для **сортировки** товаров по цене.

*   **Использование `useSelector` и `useDispatch`:**
    - Компонент `CatalogPage.js` активно использует хук `useSelector` для получения данных о товарах, фильтрах и модальном окне из `store`.
    - `useDispatch` используется для отправки всех действий (actions), таких как добавление товара, изменение поискового запроса, открытие модального окна и т.д.

*   **Интеграция React Router:**
    - Навигация между страницами (`/`, `/catalog`, `/about`) настроена в `App.js`.
    - Компонент `LinkContainer` из `react-router-bootstrap` используется в `Header.js` для корректной работы ссылок.

*   **Поддержка интернационализации (i18next):**
    - Приложение настроено для поддержки двух языков: русского (`ru`) и английского (`en`).
    - В `Header.js` добавлен переключатель языков.
    - Все статичные тексты интерфейса (заголовки, кнопки, подписи) вынесены в файлы `public/locales/{lng}/translation.json`.
    - Динамический контент (названия и описания товаров) также переводится благодаря обновленной структуре `products.json`.

*   **Отзывчивый дизайн:**
    - Обеспечен с помощью сеточной системы (`Row`, `Col`) и адаптивных компонентов (`Navbar`) из библиотеки React Bootstrap.
