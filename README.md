# SPA-приложение "Custom Clothes"

Это одностраничное приложение (SPA) для демонстрации каталога кастомной одежды, разработанное в рамках лабораторных работ.

## Лабораторная работа №3

В рамках данной работы была проведена интеграция с библиотекой компонентов **React Bootstrap**.

### Использованные компоненты (15):

1.  **Container** - для основной разметки и центрирования контента.
2.  **Navbar** - для создания адаптивной шапки сайта.
3.  **Nav** - для навигационных ссылок в шапке.
4.  **Stack** - для удобного расположения элементов в футере.
5.  **Row** - для создания адаптивной сеточной разметки.
6.  **Col** - для создания колонок в сеточной разметке.
7.  **Card** - для оформления карточек товаров в каталоге.
8.  **Button** - для всех интерактивных кнопок.
9.  **ButtonGroup** - для группировки кнопок на карточке товара.
10. **Modal** - для всплывающих окон (просмотр, редактирование, добавление).
11. **Image** - для стилизованного отображения изображений.
12. **Form** - для создания форм (поиск, редактирование, добавление).
13. **Dropdown** - для создания выпадающего меню сортировки.
14. **Badge** - для отображения статуса наличия товара.
15. **Tooltip** - для всплывающих подсказок при наведении.

### Новые функции:

1.  **Поиск по каталогу**: на странице каталога добавлено поле для фильтрации товаров по названию.
2.  **Сортировка товаров**: на странице каталога добавлена возможность сортировки по цене (дешевле/дороже).
3.  **Статус наличия товара**: на карточках товаров отображается их статус ("В наличии" или "Под заказ").
